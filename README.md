# personal-finance-manager
A full-stack personal finance management system built with Spring Boot, React, and PostgreSQL.

## 📖 Overview

This project is a full-stack web application developed to practice enterprise software development using Spring Boot and React. It allows users to manage personal finances by tracking income, expenses, categories, and financial reports.
